# 期现瞭望 · `dsh-basis-watch`

[English](README.md) | 简体中文

一个 DSH（DeepSeek Harness）插件：把公开的行情源变成**本地优先**的 **基差/贴水、跨品种价差、期限结构与注册仓单**观察台。

当前发布版本 **0.2.0**，变更记录见 [CHANGELOG](CHANGELOG.md)。

目前十个板块（76 个品种，含氢氧化锂预留位）：

- **油脂油料**：豆粕 / 豆油 / 棕榈油 / 菜油 / 菜粕 / 豆一 / 豆二 / 葵油，基差 = 现货 − 期货，带仓单；
- **黑色**：螺纹钢 / 热卷 / 铁矿石 / 焦炭 / 硅铁 / 锰硅 / 不锈钢，带仓单，另有螺矿比、卷螺差；
- **能化**：PTA / 甲醇 / 尿素 / 纯碱 / PX / 短纤 / 瓶片 / 聚乙烯 / 聚丙烯 / PVC / 乙二醇 / 苯乙烯 /
  橡胶 / 20号胶 / 纸浆 / 纯苯 / 丁二烯橡胶 / 玻璃 / 烧碱 / 石油沥青 / 丙烯；
- **有色**：铜 / 铝 / 锌 / 镍 / 锡 / 铅 / 氧化铝 / 国际铜 / 铸造铝合金，基差 = 现货 − 期货；
- **农产品**：白糖 / 棉花 / 棉纱 / 玉米 / 玉米淀粉 / 鸡蛋 / 生猪 / 红枣 / 苹果 / 花生；
- **贵金属**：黄金 / 白银 / 铂 / 钯，附金银比；
- **新能源**：碳酸锂 / 工业硅 / 多晶硅 / 氢氧化锂（广期所 LI，已发布合约、上市时间待定，先预留槽位）；
- **能源**：原油 SC / 液化气 PG / 燃料油 FU / 低硫燃料油 LU —— 国内没有可比现货，口径是
  **Brent × 汇率 × 系数** 的折算价，页面明确标注「内外价差」，不是国内现货基差；
- **其他**：关联度较低的品种集合，当前放集运欧线 EC（对比 SCFIS 欧线结算指数，周度），后续同类不相关的合约也放这里；
- **中金所**：股指 IF/IH/IC/IM（基差 = 期货 − 指数，即贴水，附年化）与国债 T/TF/TS/TL（只做期限结构与跨期；
  真正的国债基差需要 CTD/IRR，免费源拿不到可交割券数据）。

现货口径不可比的品种**仍然收录**，但基差列会明确标注原因（如烧碱折百、20号胶保税价、苹果/红枣无免费现货）；玻璃按平米、鸡蛋生猪按公斤的报价会先折到期货单位再算基差。

板块切换放在**最外层标题行**，不放进某个页签内部：板块决定基差口径、有没有仓单、资讯来源，
所以它必须对所有页面同时生效。

网络只负责增量追加数据，所有统计、图表与分位都由本地文件计算，断网也能看，历史不会被静默改写。

- **设置 → 期现瞭望** 开启侧边栏入口，或按 <kbd>Shift</kbd>+<kbd>Cmd</kbd>+<kbd>D</kbd> 随时切换。
- 不做综合评分、不给「高估/低估」结论，只给统计位置，并在每处标注口径。

## 功能

- **总览**：品种表格（最新价、涨跌、基差率、3 年分位、仓单）、价格/基差双轴图、价差快照、
  最新资讯、分位图例
- **品种详情**：关键数字、价格分位（1/3/5/10 年）、基差分位、仓单曲线、K 线、基差率走势、
  季节性分位带、跨期结构、相关价差、外盘参考、数据完整度、相关资讯。中金所详情把「基差」换成「贴水」，
  并给出年化贴水与主力合约到期天数；国债详情明确说明没有现货基准，不编造基差
- **板块切换**：标题行的下拉菜单（油脂油料 / 黑色 / 能化 / 有色 / 贵金属 / 能源 / 农产品 / 新能源 / 其他 / 中金所），切换后所有页签同时生效；中金所没有仓单，总览的仓单列与详情的注册仓单卡不显示
- **套利**页分两种：**跨品种**（油粕比、豆棕、菜豆油、豆菜粕）与**跨期**（按当日持仓量选合约，
  **任意两个交割月配对**，价差按交易所口径"近月−远月"，给价差率 / 年化 / 同合约对历史分位）
- **资讯** 子页：跟随当前板块与标签（中金所显示交易所公告 + 关键词筛选后的快讯）；
  社库/厂库/开工率等供需数据在 Mysteel/SMM/卓创/隆众为付费数据，免费源拿不到完整序列，因此不做独立供需页
- **Agent 只读工具**：`oils_overview`、`oils_detail`、`oils_spreads`、`oils_term`、`oils_news`
- 自适应布局；图表全部手绘 SVG（零图表依赖）；术语答疑弹层解释基差、分位、z 值等概念
- 数据缺失不伪造：没有现货源显示「无现货源」，样本不足显示「样本不足」，不填 0、不拿旧值顶替
- 插件标题/描述跟随宿主语言（`locale/en.json`、`locale/zh.json`），界面文案目前为中文

## 安装

```bash
git clone https://github.com/codeway3/dsh-basis-watch.git
cd dsh-basis-watch
dsh plugin --profile web add link:$PWD
```

需要 **DSH ≥ 0.1.7-rc.2**、**Node.js ≥ 22**；无运行时依赖，`react` 由宿主提供。安装后重启
`dsh web`。

数据落在仓库之外：`<DSH_HOME>/dsh-basis-watch/data/`
（`daily/ basis/ stock/ news/ quotes/ continuous/ meta.json`）。

## 数据源

| 数据 | 通道 | 历史深度 | 限制 |
|---|---|---|---|
| 内盘行情 | 新浪 `hq.sinajs.cn` | 实时 | 需要 GB18030 + Referer；中金所字段布局与商品不同 |
| 日线（主连 + 分级合约） | 新浪 `getDailyKLine` | 2005 至今 | 取最近 4 个合约 |
| 指数点位（股指现货腿） | 新浪 `s_sh000300` 实时 + 东财日线历史 | 指数 2005 至今 | 3 年分位需要长历史，所以用东财补 |
| 现货 / 基差 | 生意社现期表 | 2019 至今 | 表里 54 个品名，只启用单位/品级可比的品种；能源用 Brent 折算、航运用 SCFIS |
| 葵油现货 | Mysteel 公开报价 | 当日多市场 | 贸易商报价聚合，非交易所基准 |
| 注册仓单 | 东财 `RPT_FUTU_STOCKDATA` | 约 67 个交易日 | 本地持续累积 |
| 新闻（油料） | 中国粮油信息网（6 个栏目） | 列表页最新条目 | 不抓正文 |
| 新闻（各板块） | 金十快讯 + 东方财富期货首页 + 新浪财经 7×24 + 中金所通知 + 粮油网 | 每次数百条候选 | 按板块关键词打标，多源同名去重，盘面综述类不计入板块 |
| 能源折算参考 | 新浪 `hf_OIL`（Brent）+ `fx_susdcny` 实时；Brent 日线走新浪外盘；USD/CNY 历史走 frankfurter.dev（ECB） | Brent 2016 至今，汇率约 6 年 | 折算口径的现货，**不是**国内现货报价 |
| 航运现货 | SCFIS 欧线指数（上海航交所，周度） | 每周一期 | 周一下午结算，盘中不更新 |
| 外盘参考 | 新浪 `hf_S / hf_SM / hf_BO / hf_FCPO` | 实时 | 仅详情页参考 |

## 口径与已知偏差（看数字前先看这里）

| 项 | 做法 | 已知偏差 |
|---|---|---|
| 连续合约 | 用具体合约日线反推主连，按**比例复权**拼接（`lib/continuous.js`） | 会缩放历史价格水平，因此**不用于价格分位** |
| 价格分位 / K 线 | 用**主连真实报价**，1/3/5/10 年各自取窗口；样本 < 窗口 75 % 标「不足」 | 换月处仍有真实跳空 |
| 回撤 / 波动率 | 比例复权序列，只取覆盖区间（约 4.8 年） | 历史比 10 年分位短 |
| 季节性 | 年内相对首日收盘的百分比，常数因子约掉，复权还能去掉年内换月跳空 | 只有约 5 个年点，分位带自动从 p10–p90 降级为 p25–p75 |
| 基差 | 生意社现货价 vs **具体合约**（如 2611），不是主连 | 与主连价格不同（2026-11 实测差约 94 元） |
| 交易日历 | 内置 2024–2027 节假日；调度按北京时间 | 2028 及以后按周末近似，`/status` 会标 `covered:false` |
| 数据时点 | `asOf` = 源站时间，`fetchedAt` = 抓取时刻 | 行情 15 分钟一轮，基差每交易日一次 |

## 命令行（不依赖 DSH 宿主）

```bash
node scripts/collect.mjs --status                     # 数据覆盖
node scripts/collect.mjs --bootstrap --years=2        # 首次回填（约 5–10 分钟）
node scripts/collect.mjs --update                     # 盘中行情 + 新闻
node scripts/collect.mjs --update --mode=close        # 收盘：日线 / 仓单 / 基差
node scripts/collect.mjs --basis --date=2026-11-06 --force
node scripts/collect.mjs --contracts --years=3        # 回填合约日线并重建复权
node scripts/collect.mjs --rebuild-continuous
```

所有写操作都走跨进程锁（`job` 短任务 / `backfill` 长任务）和按数据集的状态机，调度器、HTTP
接口与命令行可以并行使用。

## HTTP 接口

```
GET /basis-watch/api?op=status | overview | detail&code=M0 | spreads | term&code=M0 | news
GET /basis-watch/api?op=update&mode=intraday|close | bootstrap&years=2 | basis&date=...&force=1
```

`op=term` 按**当日持仓量**取前几个合约（默认 5 个），**任意两个交割月配对**，返回价差（近月−远月，
交易所组合指令口径）、价差率、年化与该合约对自身的历史分位。分位只在同一合约对内部有意义。

## 开发

```bash
npm install          # 只为自测装 react/react-dom（devDependencies）
npm run check        # 语法检查
npm run selftest     # data / host / correctness / client / shortcut / manifest
npm run selftest:all # 上面这些 + SSR 冒烟 + 表格审计（需要先 npm install）
```

`FR_REACT_DIR` 指向包含 `react` 与 `react-dom` 的 `node_modules`（插件本身不带依赖）。版本变更见 [CHANGELOG.md](CHANGELOG.md)。

浏览器半边拆成 `src/client/*.js` 多个有序片段，由 `npm run build:client` 拼成 `client.js`（不用打包器：
DSH 客户端半必须是普通脚本）。改完片段记得重新生成；`npm run check` 会在 `client.js` 过期时报错。

- `client.js` 改动在运行中的 DSH 里热更新；
- `index.js` / `lib/*` 改动需要在 **设置 → 插件** 里关掉再打开一次插件。
